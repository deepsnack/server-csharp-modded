双轨奖励表

滚动浏览全部等级，逐级编辑免费 / 付费轨奖励。奖励 type：item（邮寄）/ purchaseRight（商人购买，填 offerId）/ recipe（配方，填 recipeId）/ title（称号，填 titleId）/ clothing（服装，填 suitId）/ lotteryGlobalTickets（通用抽奖券）/ lotteryPoolTickets（奖池限定抽奖券，填 poolId）/ lotteryExchangeCoins（抽奖兑换币）。满级后进入「♾️ 循环奖励」轮次（列表最底部，逐轮可领）。

批量添加一种奖励

把下方奖励追加到指定等级范围，不覆盖这些等级已有的奖励。可设置间隔，例如 1–50 级、每 5 级添加一次。

奖励总览 · 搜索 / 筛选 / 批量移除

汇总所有等级与双轨的已配置奖励；可按关键字 / 类型 / 轨 / 等级范围筛选，并对筛选结果一键批量移除（立即保存）。循环奖励按等级 0 计。
